  Régression sur données réelles  

Pour ce projet, nous devions créer un modèle permettant de prédire le plus précisément possible des prix de vente de logement, puis rédiger un texte explicatif de notre démarche. Pour parvenir à ce projet nous avions à disposition un jeu d’essai pour nous entraîner à calculer des prix de vente. Ce jeu d’essai contenait des données selon plusieurs variables comme le type de logement en vente ou encore la surface du logement. Le logiciel de programmation statistique R a été utilisé pour faire ces calculs.

Afin de construire notre modèle de prédiction, il fallait d’abord choisir la variable qui nous permettrai de prédire le prix de vente du logement, des recherches nous ont permis de déterminer que la plus pertinente serait la surface du logement, et puisque la localisation est importante aussi, nous avons décidé de calculer pour chaque ville un modèle permettant de prédire le prix de vente selon la surface du logement.

Pour optimiser notre code et ne pas écrire plusieurs fois les mêmes calculs pour chaque ville, nous avons mis en place des fonctions permettant d’écrire une fois le code et de l’appliquer à chacune des villes.

Compétences acquises :

  • Développement de mes connaissances en R (syntaxe, structure)
  • Compréhension du fonctionnement et contextes d’usage de la régression linéaire
  • Amélioration des mes compétences rédactionnelles
