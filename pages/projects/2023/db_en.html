  Designing and building a database  

The goal of this project was to build a database that met the client's needs as closely as possible. In this case, we had to build it for a woodworking company, to track changes to its equipment (repairs, purchases, equipment type, type of users). The final database had to come with a graphical interface coded in Python, to let the users view and interact with the contents of the database, such as running certain specific queries (for example, asking the database for the total equipment purchases made in 2021).

Before building the database, we created a relational diagram showing what we wanted to build and highlighting the links between the different tables of the database. This let us visualize the database and check whether the model we had in mind would actually work. Then, once the relational diagram was ready, we built the database from it. The database was hosted on EasyPHP. The graphical interface was entirely coded in Python; it can add data to the database, display it, and also run different queries, which are then shown on screen.

Skills learned:

  • Using LoopingMCD and EasyPHP
  • Improving my knowledge of Python and SQL
  • Designing a database
  • Building an interface that is easy to use and interactive for users
  • Understanding the needs and requests of a client
