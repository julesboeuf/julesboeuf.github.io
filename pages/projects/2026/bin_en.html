  Simulating DNA Repair  

The goal of this group project was to simulate the spatial dynamics of PARP1 proteins on damaged area of DNA. PARP1 plays an important role in DNA repair: it attaches itself to damaged areas and then will mobilizes various molecules that will carry out the repairs.

In order to describe and simulate how it moves to a damaged DNA area, simplified models were built using two methods : a random (stochastic) model and a fixed (deterministic) model.

The first step was to collect experimental data in a lab, so we could be able to build and optimize our model. We used cells that were modified, by our project tutor, to produce PARP1-GFP proteins, which makes the proteins glow under certain lights. Our protocol was to damage a small area of DNA in the cell nucleus on purpose, then take pictures every two seconds to watch PARP1 arrive and then leave. To measure the evolution of PARP1 amount inside the cell, the pictures were processed using the Fiji software. In these pictures, the PARP1 amount was measured on three area : the damaged area, the rest of the nucleus, and an area outside the cell. The data was then corrected and standardized.

The first simulation model used a deterministic approach, with a system of equations describing how PARP1 spreads over time and space.

The second model used a stochastic approach. It simulated the movement of each PARP1 molecule in the cell using a random-walk type method. This meant watching the movement of each molecule and giving it a tag depending on whether it was in the damaged DNA area or not.

The parameters of the models were then optimized using a grid search, in order to find the best values. All the scripts were written in Python.

The project ended with a written report and an oral presentation.

Skills learned:

  • Using the Fiji software to process images
  • Simulating a biological process in Python
  • Building and checking a mathematical model using experimental data
  • Tuning the parameters of a model
  • Writing a scientific report
  • Handling and visualizing data with Python
  • Deepening my knowledge in basic biology
