  Jeu Collapsi  

Pour ce projet de groupe, l’objectif était de produire la version virtuelle d’un jeu de carte se nommant Collapsi. Le jeu devait être codé en Python et jouable depuis une invite de commande. Le but était de nous sensibiliser aux bonnes pratiques de programmation en Python, afin de réfléchir sur la manière de produire des scripts.

Le jeu s’est décomposé en une multitude de fonctions qui permettaient de gérer chaque aspect d’une partie de carte : récupération de l’entrée de l’utilisateur, vérification des coups valides, ou encore définition des conditions de victoire. La gestion des erreurs était également importante pour ce projet, où il a été nécessaire de prévoir la plupart des cas. Plusieurs fonctions de test ont alors été mises en place afin de vérifier le bon fonctionnement de chaque fonction.

Une fois que le jeu fut fini, nous avons fait le choix de développer une interface graphique avec la librairie GTK3+ pour que les utilisateurs puissent jouer autrement qu’avec l’invite de commande. Une intelligence artificielle a également été implémentée dans le jeu afin de proposer un adversaire.

Le projet a été rendu sous la forme d’un script Python, et une présentation orale a été réalisée pour présenter les résultats.

Compétences acquises :

  • Gestion d’un projet sur GitHub
  • Création d’une interface dynamique et interactive en Python GTK3+
  • Utilisation de bonnes pratiques de développement (fonctions de tests, DocString, commentaires)
  • Approfondissement des connaissances en Python
  • Réalisation d’une présentation orale
