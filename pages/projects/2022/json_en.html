  Reading and writing data files (JSON and CSV)  

This group project involved building a Python program that takes data in JSON format and returns a CSV table with the same data, sorted, filtered, and ordered by chosen columns. We worked with a data set on air pollution levels. We were given several extra requirements for this project: we had to remove incomplete rows of data, and also handle date formats (which were written in English).

To do this, we first had to understand the structure of the data we were going to change and send to the CSV file, which was possible thanks to a website made for viewing JSON files.

The program could then read each row of data, convert the date into French format, and remove the row if it was incomplete, before writing it to the CSV file.

Skills learned :

  • Understanding how important it is to know a data set's structure
  • Deepening my Python skills
  • Understanding basic algorithm structures
  • Working with JSON and CSV file types
  • Understanding the needs and requests of a client
