  Fixed-term contract at INRAE  

This fixed-term contract took place in the URP3F unit at the INRAE research center in Nouvelle-Aquitaine-Poitiers, in Lusignan (FRANCE). This contract was next part of my work from my second-year internship (BUT2), which goal was to code and test statistical methods used to summarize years of meteorological data into one single representative year. These methods are called "typical meteorological years".

After producing meteorological data representing the weather of the city of Lusignan, new methods were explored during this contract to try to produce extreme meteorological years. A bibliographic research led to choosing 4 methods, which were then coded in a Python script.

The second part of the contract involved writing R scripts to produce microclimate indicators, which describe the weather conditions of an area. For this, I had a literature review with the formulas usually used. These were coded as functions to make them easier to use. They would be used later to measure the accuracy and features of the typical meteorological years.

The last task during this contract was coding and optimizing scripts used to study the amount of solar radiation on a 3D surface. The context was to simulate how solar radiation is spread across a football stadium located in Nantes (FRANCE). This required to build a 3D model of the stadium by using the VGX format. The simulation was run on an existing Python script that was improved by adding multi-threading. Originally, the last step of the simulation was done in a MatLab script, but this had to be converted into an R script, which is much more efficient on matrix calculations.

Skills learned:

  • Using Python and R
  • Learning the basics of multi-threading in Python
  • Searching scientific literature
  • Maintaining and improving a script
  • Building statistical climate indicators
