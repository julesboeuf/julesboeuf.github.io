  Data Warehouse  

The goal of this group project was to build a database that used a Star schema for a fictional sports company. Working with several types of files, we had to sort, clean, and automatically load data into the different tables of the database.

The first step was loading and cleaning the data. The company's data was saved across several files in different formats: .csv, .mdb, .xls, and .txt. This part was done in Python. Once loaded, we put the data in their respective tables by joining on shared keys; but the files had duplicate entries, which caused errors during the joins, so these duplicates had to be removed to fix the problem. The tables were then filtered to keep only the data we needed, and cleaned by fixing date formats, data class, and some invalid separators (for example, dates written as MM//DD/YYYY instead of DD/MM/YYYY).

Once the cleaning was done, we had to connect the DataBase to Oracle, a database management tool. A Python library allowed us to do this, by creating the tables that did not already exist in the database.

The last step was sending the data to Oracle, which was done using Talend, a tool that moves data from one source to another and lets you to manage file imports into Oracle.

After loading the data into Oracle, a dashboard to display the sports company's data was built using Power BI. This dashboard tracks the company's performance across several areas: geography, time, production, staff, and customers.

A report was written at the end of the project to summarize all the steps.

Skills learned:

  • Using an ETL tool (Talend)
  • Using a database management tool (Oracle)
  • Writing a script to develop a full data pipeline, from collecting data to saving it in a database
  • Deepening my knowledge of Python (cleaning and exporting data)
  • Handling data from multiple sources (CSV, MDB, TXT, XLS)
  • Building a database that meets a client's requirements and follows a given structure
  • Producing documentation that summarizes the work done
  • Building a Power BI dashboard and connecting it to a DataBase
