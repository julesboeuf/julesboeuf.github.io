  Expliquer ou prédire une variable quantitative à partir de plusieurs facteurs  

Dans le cadre de ce projet, nous avons vu l’utilisation du Machine Learning sous Python pour estimer la valeur de biens immobiliers. Pour réaliser cela, nous disposions de plusieurs variables de données concernant des blocs de maisons, telles que : le revenu médian, la localisation géographique du bloc, le nombre de chambres, la population. Nous avons alors écrit un script en Python permettant d’estimer la valeur de ces blocs.

L’estimation des prix était d’abord précédée par une phase de nettoyage des données, il fallait gérer les valeurs manquantes et les valeurs extrêmes. Puisque nous avions 20300 lignes de données et seulement 7 valeurs manquantes, nous avons décidé de supprimer directement les lignes concernées car nous considérions qu’il restait assez de données pour se le permettre. Pour les valeurs extrêmes, une analyse du jeu de données a indiqué que les données n’étaient pas homogènes, certaines variables étaient beaucoup plus dispersées que d’autres. Plusieurs méthodes différentes de gestion de valeurs extrêmes ont été testées pour résoudre cela.

Une fois que les données étaient prêtes, nous pouvions commencer à estimer les valeurs des biens immobiliers. La librairie Python « SciPy » proposait des commandes permettant de mettre en place un modèle de Machine Learning faisant de la régression linéaire multiple, ce qui correspondait à nos besoins. Nous avons alors séparé les données en deux jeux de données différents : un d’entraînement et un de test pour valider le modèle. Pour entraîner le modèle, nous avons utilisé la méthode de la validation croisée, qui consiste tester les performances du modèle en séparant les données en sous-groupes qui alterneront entre jeu d’entraînement et jeu d’essai. Une fois que le modèle était entraîné, nous pouvions faire des estimations. Le modèle a été testé avec différentes méthodes de gestions de valeurs extrêmes, pour voir si cela changeait les résultats. La méthode donnant les meilleurs résultats était celle où l’on conservait les valeurs extrêmes.

Pour finaliser le projet, un rapport a été rédigé, résumant les étapes que l’on a suivi pour atteindre nos résultats.

Compétences acquises :

  • Approfondissement de mes connaissances en Python
  • Utilisation et apprentissage de méthodes de gestion des valeurs extrêmes
  • Apprentissage des principes et de l’utilisation du Machine Learning
