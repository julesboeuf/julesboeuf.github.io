  Portfolio (updated)  

The goal of this project was to build a portfolio that would work as a professional tool listing the projects I did during my first two years in the Data Science course (BUT Science des Données). In this portfolio, you can find my resume, my projects, and a personal review looking back on how I felt about my second year of studies, along with my plans for the future.

A first version of this portfolio had already been built the year before, at the end of my first year of studies. I decided to rebuild the website's structure to improve it. One issue with the old portfolio was that the elements on the screen could overlap depending on the size of the screen used to view the site; this was fixed. On top of that, adding animations and changing some page elements made it more visually appealing.

This website was entirely coded in HTML and CSS, while following good coding practices to make the portfolio easier to update, such as: sorting scripts into set folders, using indentation in the scripts to clearly show the site's structure through the code, and adding comments to make the code easier to read.

Skills learned:

  • Maintaining a website
  • Deepening my knowledge of HTML and CSS
  • Building a portfolio that summarise my work
  • Improving my writing skills
  • Building a website that is easy to use and interactive
  • Giving a clear summary of my work and reflecting on my work
