  Learning Qliksense  

The goal of this project was to build a dynamic, interactive dashboard for customer service employees at Groupama, using only Qliksense. The requested features could be grouped into three parts. First, we needed to make information easy to access by adding filters at different levels: by region, by type of organization, or by type of contract. Several statistical metrics were needed to track different performance goals, such as contract conversion rates and electronic signature rates. The company's activity also had to be tracked from a page dedicated to phone calls and appointment.

These different pages were linked together inside a menu, along with a glossary explaining how the app worked. The data we were given covered the different Groupama branches over the past three years. Using this data in Qliksense, we built a database schema to link the different files together.

The final app was made visually appealing by reusing the company's colors. An oral presentation of the dashboard was given during the project to show our progress.

Skills gained:

  • Building a dynamic interface
  • Learning how to use Qliksense
  • Preparing for an oral presentation
  • Analyzing and building a database schema
  • Visualizing data and choosing metrics that fit the context
