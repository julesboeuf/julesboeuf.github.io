  Introduction to Neural Networks  

For this project, we had to build and optimize two neural network models. The goal was to get a model that could be classifying 1,000 images into 10 different categories. Two methods were tested: one based on feature descriptors, and one based on deep learning.

In the first attempt, the features of the images were converted into numbers using different descriptors, which break down each part of an image (colors, shapes, number of lines, number of corners) into numerical data. Our model was a multilayer perceptron, meaning a neural network made of several layers of neurons, where each layer connects to the next one. The data was cleaned and split into a training and a test dataset, using Python. To get the best possible results, several methods were used to avoid overfitting: normalizing the data, randomly turning off some neurons during training, and reducing the number of layers or neurons. In the end, we reached an average accuracy of 70% after 40 epochs. By testing other types of image descriptors, we reached a top F1 score of 84%, which means that the model was good at classifying the images.

The second approach worked with the images themselves, without descriptors, using convolution layers. These consist of a series of filters that scan an image and keep the most important features to summarize that data. This pieces of information is then reduced down to a size that neuron layers can use to classify the images, like in the first model. We had to prepare the images by resizing them all to 200x200 pixels and normalizing their colors. In the end, we reached an accuracy of 76.5%, which is good but lower than the first approach. Our final model kept only one convolution layer, followed by a layer of 16 neurons and an output layer.

Other methods were tested to improve the results, such as data augmentation, which creates variations of the images in the training dataset so the model has more data to learn from. But this did not improve the score. Transfer learning was another option we tried, but it also was not enough.

The project ended with a report describing the steps we followed to complete the work.

Skills learned:

  • Knowledge of how neural networks work and how to improve them
  • Writing a report
  • Setting up statistical metrics to analyze a model performance
  • Identifying the limits of a model
  • Comparing different approaches to neural networks
