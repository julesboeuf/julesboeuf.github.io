  Statistical study in a specific field  

This project was given to us by someone from Inter Mutuelle Assistance (IMA), we had to build two Machine Learning models to predict the daily number of cases expected over the next 15 months. To do this, we were given a file containing the number of phone calls recorded from 2013 to 2024. The cases were splitted into two groups: those covering trips under 50 km, and those covering trips over 50 km.

We first studied and got familiar with the data to better understand the variable we needed to predict. This allowed us to see a clear break in activity during the Covid period, caused by a drop in the number of trips at that time. To make sure our data was ready to be used in a Machine Learning model, this bias had to be corrected to improve prediction quality. After clearly identifying the affected data, it was replaced with the average of the previous three years, which removed these biases.

New variable were added to the data in order to have new pieces of information, by creating new True/False variables from the dates. For example : whether a date falls on a weekend, during a holiday period. Adding this information gave our models some useful new variables.

We chose to predict only the number of cases covering trips over 50 km. Once the data was ready, two models were built using R. The first was a multiple linear regression, and the second was a time series model. The second model was chosen because the data showed seasonal patterns with cycles of 366 periods. The models were trained and tested on two separate data sets, and the results were good: an R² of 84% for the first model, and 90% for the second.

To make it easier to share the predictions, a dynamic interface was built in Power BI. This let users view the predictions and compare them with real activity. A report was also written at the end of the project.

Skills learned:

  • Using and understanding Machine Learning use cases
  • Understanding the needs and requests of a client
  • Building a dynamic graphical interface
  • Using multiple linear regression in R
  • Building a time series model
  • Writing a report
  • Choosing a statistical model that fits the context
